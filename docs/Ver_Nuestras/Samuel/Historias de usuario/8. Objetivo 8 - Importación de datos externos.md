
**Historia de Usuario 8.1: Importación de datos externos**
- **Como** usuario
- **quiero** importar mis datos desde fuentes externas
- **para** evitar tener que introducirlos manualmente.
**Criterios de Aceptación:**
1. **Criterio de importación de datos**
	- **Dado** que el usuario quiere importar datos externos
	- **cuando** el usuario indique la localización y el formato del recurso
	- **entonces** si el formato del recurso es soportado, se importarán los datos a su cuenta
