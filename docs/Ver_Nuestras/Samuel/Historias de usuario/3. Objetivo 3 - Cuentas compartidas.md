

**Historia de Usuario 2.1: Crear cuenta compartida**
- **Como** usuario
- **quiero** crear una cuenta compartida
- **para** gestionar cuánto le toca pagar a cada uno dado un cierto contexto
**Criterios de Aceptación:**
1. **Criterio de establecer nombre**
	- **Dado** que el usuario quiere crear una cuenta
	- **cuando** el usuario intente crear una nueva cuenta compartida
	- **entonces** el sistema le pedirá el nombre de la cuenta
2. **Criterio de establecer integrantes**
	- **Dado** que el usuario quiere diferenciar los integrantes de la cuenta compartida
	- **cuando** el usuario intente crear una nueva cuenta compartida
	- **entonces** el sistema le pedirá quiénes forman parte de ella
3. **Criterio de distribución de gastos**
	- **Dado** que el usuario quiere distribuir el porcentaje de gasto por persona
	- **cuando** el usuario intente crear una nueva cuenta compartida
	- **entonces** el sistema le pedirá el porcentaje de gasto asumido por cada persona
4. **Criterio de distribución de gastos por defecto**
	- **Dado** que el usuario no ha introducido los porcentajes de gasto
	- **cuando** le de a crear cuenta compartida
	- **entonces** el sistema asumirá que los porcentajes de gasto se reparten de forma igualitaria
5. **Criterio de corrección de proporciones**
	- **Dado** que el usuario ha introducido los porcentajes de gasto
	- **cuando** le de a crear cuenta compartida
	- **entonces** el sistema comprobará que los porcentajes suman 100 %. Si no es así, impedirá crear la cuenta e informará al usuario


**Historia de Usuario 2.2: Borrar cuenta compartida**
- **Como** usuario
- **quiero** borrar una cuenta compartida
- **para** eliminar cuentas que ya no necesito
**Criterios de Aceptación:**
1. **Criterio de doble verificación**
    - **Dado** que el usuario quiere eliminar una cuenta
    - **cuando** seleccione la opción de eliminar
    - **entonces** el sistema solicitará una confirmación antes de eliminarla
2. **Criterio de aceptación**
    - **Dado** que el usuario está en la pantalla de confirmación
    - **cuando** confirme el borrado
    - **entonces** se eliminarán la cuenta y todos los registros de gastos asociados


**Historia de Usuario 2.3: Ver cuenta compartida**
- **Como** usuario
- **quiero** ver una cuenta compartida ya creada
- **para** consultar los gastos compartidos de los integrantes.
**Criterios de Aceptación:**
1. **Criterio de vista de lista de cuentas**
	- **Dado** que el usuario quiere ver una cuenta compartida
	- **cuando** seleccione la lista de cuentas compartidas
    - **entonces** el sistema mostrará las cuentas compartidas existentes
2. **Criterio de selección de cuenta compartida**
	- **Dado** que el usuario está en la lista de cuentas compartidas
	- **cuando** seleccione una cuenta compartida
    - **entonces** el sistema mostrará por defecto los gastos compartidos del primer integrante establecido en dicha cuenta


**Historia de Usuario 2.4: Añadir registro**
- **Como** usuario
- **quiero** crear registros de gastos compartidos
- **para** almacenar mis gastos en la aplicación
**Criterios de Aceptación:**
1. **Criterio de datos necesarios**
	- **Dado** que el usuario quiere añadir un registro de gasto compartido
	- **cuando** registre su fecha, importe, persona responsable y, opcionalmente, su categoría
	- **entonces** el sistema almacenará el registro en la cuenta compartida vinculándolo a la persona responsable
2. **Criterio de datos obligatorios**
    - **Dado** que el usuario quiere añadir un registro de gasto
    - **cuando** no introduzca alguno de los datos obligatorios: fecha, importe y persona responsable
    - **entonces** el sistema impedirá guardar el registro e informará de los datos que faltan.

**Historia de Usuario 2.5: Borrar un registro**
- **Como** usuario
- **quiero** borrar un registro de gasto compartido
- **para** corregir los gastos que tengo almacenados
**Criterios de Aceptación:**
1. **Criterio de eliminación de registro**
    - **Dado** que el usuario está en la pantalla de cuenta compartida de un responsable de gasto
    - **cuando** el usuario seleccione la opción de eliminar el registro
    - **entonces** el sistema eliminará el registro.

**Historia de Usuario 2.6: Modificar un registro**
- **Como** usuario
- **quiero** modificar un registro de gasto compartido
- **para** corregir un error que he tenido al introducir los datos
**Criterios de Aceptación:**
1. **Criterio de modificación de registro**
	- **Dado** que existe un registro de gasto en la cuenta compartida
	- **cuando** el usuario modifique alguno de sus datos
	- **entonces** el sistema actualizará el registro con los nuevos datos.
2. **Criterio de validación de datos**
    - **Dado** que el usuario quiere modificar un registro
    - **cuando** introduzca datos no válidos
    - **entonces** el sistema impedirá guardar los cambios e informará del error.
