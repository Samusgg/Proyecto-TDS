
**Historia de Usuario 1.1: Añadir categoría**
- **Como** usuario
- **quiero** crear categorías
- **para** tener mis gastos agrupados y ordenados
**Criterios de Aceptación:**
- **Criterio de creación de categoría**
    - **Dado** que el usuario quiere crear una categoría
    - **cuando** introduzca un nombre válido para la categoría
    - **entonces** el sistema creará la categoría y la añadirá a su listado.
- **Criterio de categorías distintas**
    - **Dado** que el usuario quiere crear una categoría
    - **cuando** introduzca un nombre que ya pertenece a otra categoría
    - **entonces**  el sistema impedirá su creación e informará de que ya existe una categoría con ese nombre.

**Historia de Usuario 1.2: Borrar una categoría**
- **Como** usuario
- **quiero** borrar una categoría
- **para** no tener categorías inútiles
**Criterios de Aceptación:**
1. **Criterio de creación de categoría**
	- **Dado** que el usuario tiene una categoría creada
	- **cuando** seleccione la opción de eliminarla 
	- **entonces** el sistema eliminará la categoría.

**Historia de Usuario 1.3: Modificar categoría**
- **Como** usuario
- **quiero** modiifcar una categoría
- **para** tener un nombre más representativo sin tener que modificar cada registro uno por uno
**Criterios de Aceptación:**
- **Criterio de modificación de categoría**
    - **Dado** que el usuario tiene una categoría creada
    - **cuando** modifique su nombre
    - **entonces** el sistema actualizará el nombre de la categoría alterando el nombre también en los gastos asociados
- **Criterio de categorías distintas**
    - **Dado** que el usuario quiere modificar una categoría
    - **cuando** introduzca un nombre que ya pertenece a otra categoría
    - **entonces**  el sistema impedirá su creación e informará de que ya existe una categoría con ese nombre.
