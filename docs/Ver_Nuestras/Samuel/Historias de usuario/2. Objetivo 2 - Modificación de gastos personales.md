

**Historia de Usuario 2.1: Añadir registro**
- **Como** usuario
- **quiero** crear registros de gastos
- **para** almacenar mis gastos en la aplicación
**Criterios de Aceptación:**
1. **Criterio de creación de registro**
	- **Dado** que el usuario quiere añadir un registro de gasto
	- **cuando** registre su fecha, importe y, opcionalmente, su categoría
	- **entonces** el sistema lo almacenará
2. **Criterio de datos obligatorios**
    - **Dado** que el usuario quiere añadir un registro de gasto
    - **cuando** no introduzca alguno de los datos obligatorios
    - **entonces** el sistema impedirá guardar el registro e informará de los datos que faltan.

**Historia de Usuario 2.2: Borrar un registro**
- **Como** usuario
- **quiero** borrar un registro de gasto
- **para** corregir los gastos que tengo almacenados
**Criterios de Aceptación:**
- **Criterio de eliminación de registro**
    - **Dado** que el usuario tiene un registro de gasto almacenado
    - **cuando** seleccione la opción de eliminarlo
    - **entonces** el sistema eliminará el registro de su cuenta.

**Historia de Usuario 2.3: Modificar un registro**
- **Como** usuario
- **quiero** modifcar un registro
- **para** corregir un error que he tenido al introducir los datos
**Criterios de Aceptación:**
1. **Criterio de modificación de registro**
    - **Dado** que el usuario tiene un registro de gasto almacenado
    - **cuando** modifique alguno de sus datos
    - **entonces** el sistema actualizará el registro con los nuevos datos.
2. **Criterio de validación de datos**
    - **Dado** que el usuario quiere modificar un registro
    - **cuando** introduzca datos no válidos
    - **entonces** el sistema impedirá guardar los cambios e informará del error.
