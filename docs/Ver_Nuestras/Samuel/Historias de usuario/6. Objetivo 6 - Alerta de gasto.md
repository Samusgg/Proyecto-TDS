
**Historia de Usuario 6.1: Crear alerta de gasto**
- **Como** usuario
- **quiero** tener alertas de límite de gasto
- **para** saber cumplir mis objetivos de ahorro
**Criterios de Aceptación:**
1. **Criterio de establecer límite de gasto**
	- **Dado** que un usuario quiere establecer un límite de gasto
	- **cuando** el usuario elija el tope y el periodo temporal (semanal o mensual)
	- **entonces** el sistema registrará el límite y estará atento a su incuplimiento
2. **Criterio de vinculación a categorías**
	- **Dado** que un usuario quiere asociar el límite a una categoría
	- **cuando** el usuario marque una categoría al crear el límite
	- **entonces** el sistema solo contará el límite para la suma de gastos de esa categoría
3. **Criterio de notificar al usuario**
	- **Dado** que el usuario ha establecido un límite
	- **cuando** el usuario trapase el límite de gasto acordado
	- **entonces** el sistema notificará al usuario
